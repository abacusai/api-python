   One conversation's spend on one UTC day (listConversationUsage).

   :param client: An authenticated API Client instance
   :type client: ApiClient
   :param billDate: The UTC day, YYYY-MM-DD.
   :type billDate: str
   :param deploymentConversationId: The conversation.
   :type deploymentConversationId: id
   :param name: The conversation title.
   :type name: str
   :param conversationType: The type of the conversation.
   :type conversationType: str
   :param chatllmProjectId: The ChatLLM project the conversation is in. Absent when it is in none, or has been deleted.
   :type chatllmProjectId: id
   :param chatllmProjectName: That project's name. Absent when the project no longer exists.
   :type chatllmProjectName: str
   :param ownerUserId: The member who owns the conversation.
   :type ownerUserId: id
   :param isDeleted: True when the conversation has been deleted; its spend survives.
   :type isDeleted: bool
   :param unit: 'usd' for enterprise organizations, 'credits' for self-serve: the unit `spend` is in.
   :type unit: str
   :param spend: Spend on that day. An estimate derived from conversation activity, not an invoice line.
   :type spend: float
   :param turns: Conversation events on that day.
   :type turns: int
