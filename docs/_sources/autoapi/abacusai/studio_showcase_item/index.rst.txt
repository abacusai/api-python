   Studio Showcase Item — one tile on Studio's Explore wall: a curated example generation, a Shorts format or an explainer template.

   :param client: An authenticated API Client instance
   :type client: ApiClient
   :param id: Stable tile identifier
   :type id: str
   :param title: Display title
   :type title: str
   :param modelName: Display name of the model credited for the example
   :type modelName: str
   :param modelId: Gen-settings key of that model (`abacus_studio` when the example is attributed to Studio itself)
   :type modelId: str
   :param type: image or video
   :type type: str
   :param aspectRatio: CSS aspect ratio, e.g. "9 / 16"
   :type aspectRatio: str
   :param imageUrl: CDN URL of the still (the poster for a video tile)
   :type imageUrl: str
   :param videoUrl: CDN URL of the full video, video and GIF tiles only
   :type videoUrl: str
   :param videoThumbUrl: CDN URL of the compressed preview clip (a GIF tile's loop), video and GIF tiles only
   :type videoThumbUrl: str
   :param prompt: The prompt the example was generated with; empty for format and template tiles
   :type prompt: str
   :param format: short (a Shorts format) or explainer (an explainer template); absent for a plain example
   :type format: str
   :param adTemplateSlug: The Shorts format a short tile opens
   :type adTemplateSlug: str
   :param tag: GIF for an image tile made with GIF output; absent otherwise
   :type tag: str
