   A single audio listener transcript search hit. Hits are grouped per session, best session first.

   :param client: An authenticated API Client instance
   :type client: ApiClient
   :param deploymentConversationId: The unique identifier of the deployment conversation the transcript belongs to.
   :type deploymentConversationId: str
   :param name: The name of the deployment conversation.
   :type name: str
   :param ownerUserId: The user id of the owner of the deployment conversation.
   :type ownerUserId: str
   :param createdAt: The timestamp at which the deployment conversation was created.
   :type createdAt: str
   :param lastEventCreatedAt: The timestamp at which the most recent event in the conversation was created.
   :type lastEventCreatedAt: str
   :param eventSequenceNumber: The sequence number of the matched transcript event within the conversation; absent for a name-only hit.
   :type eventSequenceNumber: int
   :param eventType: The type of the matched transcript event.
   :type eventType: str
   :param transcriptCreatedAt: The timestamp at which the matched transcript event was created.
   :type transcriptCreatedAt: str
   :param snippet: The matching transcript snippet.
   :type snippet: str
   :param matchKind: What matched: 'line' (a transcript line), 'summary' (the session's latest summary) or 'name' (the session name only).
   :type matchKind: str
   :param nameMatched: Whether the session name matches the query.
   :type nameMatched: bool
   :param sessionLineHits: How many transcript lines of the session match the query.
   :type sessionLineHits: int
   :param speaker: Who said the matched line, when known.
   :type speaker: str
