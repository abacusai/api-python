   Credits one conversation spent on a single day (_getConversationCreditsForDay).

   :param client: An authenticated API Client instance
   :type client: ApiClient
   :param deploymentConversationId: The ID of the deployment conversation.
   :type deploymentConversationId: id
   :param name: The conversation title.
   :type name: str
   :param conversationType: The type of the conversation.
   :type conversationType: str
   :param isDeleted: True when the conversation itself has been deleted; its credits survive.
   :type isDeleted: bool
   :param unit: 'credits' for self-serve, 'usd' for enterprise -- the unit `credits` is expressed in.
   :type unit: str
   :param credits: Spend on the requested day only, not the conversation's lifetime.
   :type credits: float
   :param turns: Conversation events on that day.
   :type turns: int
