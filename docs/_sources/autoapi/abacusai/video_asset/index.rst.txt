   Video Asset — reusable generation collateral (a product or app today; extensible by asset_type).

   :param client: An authenticated API Client instance
   :type client: ApiClient
   :param videoAssetId: The ID of the video asset
   :type videoAssetId: id
   :param assetType: The kind of collateral (product, app)
   :type assetType: str
   :param name: The asset's display name
   :type name: str
   :param sourceUrl: The page the asset was scraped from, if any
   :type sourceUrl: str
   :param imageUrls: Full-size signed URLs of the stored images (hero first), generated at read time
   :type imageUrls: list
   :param thumbnailUrls: Signed URLs of the card-sized copies, same order as image_urls (falls back to the full image where there is none)
   :type thumbnailUrls: list
   :param sourceImageUrls: Signed URLs of the photos those images were generated from, if any
   :type sourceImageUrls: list
   :param sourceThumbnailUrls: Signed URLs of the card-sized copies of those photos, same order and same fallback
   :type sourceThumbnailUrls: list
   :param urls: Extra product links attached as research material
   :type urls: list
   :param documentNames: Names of the uploaded documents attached as research material
   :type documentNames: list
   :param createdAt: The creation timestamp
   :type createdAt: str
   :param updatedAt: The last update timestamp
   :type updatedAt: str
