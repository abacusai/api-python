   Bases: :py:obj:`abacusai.return_class.AbstractApiClass`


   The outcome of rewriting a Listener session's summary from the owner's instruction.

   :param client: An authenticated API Client instance
   :type client: ApiClient
   :param summary: The summary the session now shows: the rewritten one, or the current one on a conflict.
   :type summary: str
   :param summarySeq: Its summary row, which the next rewrite or save must name.
   :type summarySeq: int
   :param summaryKind: Where it came from: model, edit or rewrite.
   :type summaryKind: str
   :param summaryAt: When that version was written.
   :type summaryAt: str
   :param version: The session's edits version after the rewrite.
   :type version: int
   :param editedAt: When the rewrite landed.
   :type editedAt: str
   :param summaryHistory: The session's summary versions, newest first.
   :type summaryHistory: list[dict]
   :param conflict: True when the summary changed elsewhere since the client read it: nothing was written, summary is the current one.
   :type conflict: bool
   :param unchanged: True when the instruction left the summary as it was: nothing was written.
   :type unchanged: bool
   :param running: True when a rewrite of this session is already running (another device, or a retry): nothing was started.
   :type running: bool
