   Bases: :py:obj:`abacusai.return_class.AbstractApiClass`


   The starter agent templates offered on the Personal Agents landing

   :param client: An authenticated API Client instance
   :type client: ApiClient
   :param templates: The templates, in display order (id/title/description/prompt/personality/avatar/color/categories/required_service_types, plus template, brand_icon, setup_checks, background_task, task_ideas and, when the org's disabled connectors rule it out, unavailable_reason where they apply). A setup check or background task needing mail/calendar carries required_service_type (MAIL / CALENDAR), required_service (the connector id it defaults to: the org's first allowed), available and connectors ([{service, scopes}]: the connectors the org allows, any one of which meets it, and the scopes the user's connection must hold). Chief of Staff is first.
   :type templates: list
   :param categories: The filter pills in display order (id/label); 'featured' is the default view.
   :type categories: list
   :param taskIdeas: Scheduled-task ideas the create-agent dialog offers (id/label/themes/name/prompt/schedule/cadence, plus routine_id, required_service_type (MAIL / CALENDAR) and uses (service types it reads when connected) where they apply). Templates without a setup checklist name theirs in task_ideas.
   :type taskIdeas: list
   :param taskIdeaThemes: The idea theme pills in display order (id/label); 'popular' is the default view.
   :type taskIdeaThemes: list
   :param serviceConnectors: Per service type (MAIL / CALENDAR), the connectors the org allows ([{service, scopes}]), so a typed task can be matched to them.
   :type serviceConnectors: dict
