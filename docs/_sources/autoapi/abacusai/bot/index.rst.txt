.. py:class:: Bot(client, botId=None, ownerUserId=None, isOwner=None, canEdit=None, ownerEmail=None, name=None, description=None, instructions=None, personality=None, memory=None, avatar=None, status=None, lifecycle=None, deploymentConversationId=None, externalApplicationId=None, lastMessagePreview=None, lastMessageAt=None, unreadCount=None, createdAt=None, schedule=None, tasks=None, channels=None, learnedPersonality=None, learnedInstructions=None, profileHistory=None, selfReview=None, playbooks=None, proactiveBudget=None, chattyGreetings=None, agentNetwork=None)

   Bases: :py:obj:`abacusai.return_class.AbstractApiClass`


   A persistent chat bot (long-running agent the user messages like a contact)

   :param client: An authenticated API Client instance
   :type client: ApiClient
   :param botId: The id of the bot.
   :type botId: str
   :param ownerUserId: The user id of the agent's owner.
   :type ownerUserId: str
   :param isOwner: Whether the caller owns the agent; False for a teammate's agent shared with the caller (via its conversation).
   :type isOwner: bool
   :param canEdit: Whether the caller may edit, delete and re-share the agent (the owner, or a teammate shared with the editor role).
   :type canEdit: bool
   :param ownerEmail: The owner's email; shared agents in _listBots only.
   :type ownerEmail: str
   :param name: The name of the bot.
   :type name: str
   :param description: The description of the bot.
   :type description: str
   :param instructions: The user-provided instructions/persona for the bot.
   :type instructions: str
   :param personality: The bot's self-maintained personality (tone, voice, quirks).
   :type personality: str
   :param memory: The bot's persistent memory notes.
   :type memory: str
   :param avatar: The avatar for the bot.
   :type avatar: str
   :param status: The current activity status of the bot (IDLE, WORKING, WAITING_FOR_USER).
   :type status: str
   :param lifecycle: The lifecycle of the bot (ACTIVE, ARCHIVED).
   :type lifecycle: str
   :param deploymentConversationId: The bot's persistent conversation id.
   :type deploymentConversationId: str
   :param externalApplicationId: The external application id associated with the bot.
   :type externalApplicationId: str
   :param lastMessagePreview: A preview of the last message in the bot's conversation.
   :type lastMessagePreview: str
   :param lastMessageAt: Unix timestamp of the last message in the bot's conversation.
   :type lastMessageAt: int
   :param unreadCount: The number of unread bot messages.
   :type unreadCount: int
   :param createdAt: Unix timestamp of when the bot was created.
   :type createdAt: int
   :param schedule: The bot's heartbeat schedule (frequency/time/day_of_week/timezone), if any.
   :type schedule: dict
   :param tasks: The bot's named scheduled tasks (daemon_task_id/name/prompt/schedule; event tasks also carry webhook_url); _describeBot only.
   :type tasks: list
   :param channels: The bot's configured messaging channels keyed by channel name; secret values are masked.
   :type channels: dict
   :param learnedPersonality: Personality the bot learned on its own from user feedback; _describeBot only.
   :type learnedPersonality: str
   :param learnedInstructions: Rules the bot learned on its own from user feedback; _describeBot only.
   :type learnedInstructions: str
   :param profileHistory: Changelog of the bot's self-edits to the learned fields (t/field/old/new, chronological; undo entries flagged); _describeBot only.
   :type profileHistory: list
   :param selfReview: Latest self-review state (n/last_t/score/note); _describeBot only.
   :type selfReview: dict
   :param playbooks: Reusable procedures the bot saved (name/body/t/uses/wins/losses, chronological); _describeBot only.
   :type playbooks: list
   :param proactiveBudget: User-set daily cap on proactive messages from high-frequency fires (hourly heartbeat + minute tasks); None when uncapped; _describeBot only.
   :type proactiveBudget: int
   :param chattyGreetings: Whether the agent says a short personal hello when the owner opens its chat in the web UI (default True); _describeBot only.
   :type chattyGreetings: bool
   :param agentNetwork: Agent-to-agent messaging state (discoverable/own_agents/contacts); _describeBot only.
   :type agentNetwork: dict
