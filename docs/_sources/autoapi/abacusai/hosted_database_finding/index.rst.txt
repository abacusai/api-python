   A database-health finding for a web app's database (_getHostedDatabaseHealth), as the hourly scan last recorded it.

   :param client: An authenticated API Client instance
   :type client: ApiClient
   :param findingId: kind:table:column, stable while the finding stands
   :type findingId: str
   :param kind: missing_index | repeated_query | substring_search
   :type kind: str
   :param severity: LOW | MEDIUM | HIGH | CRITICAL
   :type severity: str
   :param query: The statement, normalized, when the finding comes from statement statistics
   :type query: str
   :param table: The table involved
   :type table: str
   :param column: The column involved, when there is one
   :type column: str
   :param execSecondsPerHour: Execution time this statement costs per hour
   :type execSecondsPerHour: int
   :param callsPerHour: How often it runs
   :type callsPerHour: int
   :param rowsPerCall: Rows it returns per call
   :type rowsPerCall: float
   :param blocksPerCall: Buffers it reads per call
   :type blocksPerCall: float
   :param meanMs: Mean execution time per call
   :type meanMs: float
   :param rows: Rows in the table, for a missing index
   :type rows: int
   :param firstSeen: When the scan first recorded this finding
   :type firstSeen: str
   :param lastSeen: When the scan last saw it
   :type lastSeen: str
   :param fixPrompt: What the agent is asked to change when the finding is sent to it
   :type fixPrompt: str
