   A session summary

   :param client: An authenticated API Client instance
   :type client: ApiClient
   :param summary: The summary of the session.
   :type summary: str
   :param templateName: The name of the Listener template the session ran with, if any.
   :type templateName: str
   :param meetingType: The meeting type of that template.
   :type meetingType: str
   :param meetingNotes: The session's notes for this meeting, returned only to the session's owner.
   :type meetingNotes: str
   :param meeting: The calendar event the session is attached to (title, times, provider, recurring), returned only to the owner.
   :type meeting: dict
   :param previousMeeting: The owner's previous session of the same meeting (id, name, created_at_ms), returned only to the owner.
   :type previousMeeting: dict
   :param feedback: The owner's rating of the session (rating 1 to 5, comment, at_ms), returned only to the owner.
   :type feedback: dict
   :param summaryShared: Whether this viewer may read the summary (always for the owner and org admins); the summary is empty otherwise.
   :type summaryShared: bool
   :param transcriptShared: Whether this viewer may read the transcript.
   :type transcriptShared: bool
   :param chatShared: Whether this viewer may read the session's chat.
   :type chatShared: bool
   :param shareParts: Which parts the owner shares, {summary, transcript, chat}; returned only to the owner.
   :type shareParts: dict
   :param canEdit: Whether the caller may save changes to the session now; returned only to the owner, and only where editing is on.
   :type canEdit: bool
   :param editBlocked: Why not, when can_edit is false: recording, paused or finishing.
   :type editBlocked: str
   :param edits: The owner's saved changes so far: version (what a save must send), at, lines, summary_seqs; returned only to the owner.
   :type edits: dict
   :param summarySeq: The sequence number of the summary row shown, which a saved summary must name; returned only to the owner.
   :type summarySeq: int
   :param editedAt: When the owner last saved a change, if ever.
   :type editedAt: str
   :param summaryEdited: Whether the summary shown was written by the owner rather than the model.
   :type summaryEdited: bool
   :param summaryKind: Where the summary shown came from: model, edit (the owner's hand), rewrite (the owner's instruction).
   :type summaryKind: str
   :param summaryAt: When that version was written.
   :type summaryAt: str
   :param summaryHistory: The session's summary versions, newest first ({seq, at, kind, base_seq, instruction, preview, from_seq}); returned only to the owner.
   :type summaryHistory: list[dict]
   :param canRewriteSummary: Whether the owner may rewrite the summary with an instruction now; returned only to the owner.
   :type canRewriteSummary: bool
